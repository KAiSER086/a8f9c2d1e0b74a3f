# Personal Source

Personal AltStore repository generator.

### KravaSign / AltStore Source URL:
```text
https://raw.githubusercontent.com/KAiSER086/a8f9c2d1e0b74a3f/main/apps.json
```

### Adding More Sources
Edit `config.json`:
- Under `upstream_sources`: Add any AltStore `repo.json` / `apps.json` URL.
- Under `github_releases`: Add any GitHub repo that publishes `.ipa` assets in its releases.
